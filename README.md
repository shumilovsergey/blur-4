# blur 😴🎧📚


Плеер для длинных аудио — книг, подкастов и лекций. Появился из желания удобно засыпать под размеренное повествование.


**Что умеет:**

- Вводишь время с клавиатуры — и сразу начинаешь оттуда. Никакого свайпа по длинной шкале в темноте
- Автовоспроизведение можно выключить: файл закончился — и тишина, не проснёшься под случайный трек
- Запоминает файл и позицию. Поставил на паузу, закрыл телефон — вернёшься ровно в то же место

---

Это мой личный плеер, здесь только то, что слушаю я. Но если хочешь такой же со своим контентом — код открытый, бери :^)
